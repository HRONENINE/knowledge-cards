# knowledge-cards · 知识卡片生成 Skill

一个 ZCode skill：把粘贴的文章或本地 Markdown/TXT 文件，提炼成 5~8 张结构化知识卡片。每张卡片包含**标题、核心知识、简明解释、例子或自测**，可直接用于复习。

## 解决什么问题

读过的长文和书籍章节合上就忘，手动整理成学习卡片又非常耗时。直接让 AI"总结一下"，得到的往往是一大段复述——重点不分层、夹带原文没有的细节、知识点不够还要硬凑。这个 skill 把"做知识卡片"固化成一套带硬约束的工作流，针对三个痛点：

1. **不知道该记什么** —— 按统一标准筛选知识点（改变理解的概念原理、可照做的方法步骤、反直觉的结论与关键数据），过渡句、客套话、营销话术一律丢弃；
2. **AI 编造与注水** —— 卡片中每个事实都必须能在原文找到依据，解释只允许重组原文信息，不引入外部知识；内容撑不起 8 张就输出更少，并说明原因；
3. **整理完就散掉** —— 输出为统一的 Markdown 卡片格式，本地文件输入自动另存为 `<原文件名>-知识卡片.md`，方便积累成自己的卡片库。

## 主要功能

**卡片格式**——每张卡片固定四个字段：

| 字段 | 要求 |
|------|------|
| 标题 | 能独立成意的完整判断句，如"间隔重复比考前突击记得更牢"，不用"要点一"式空标题 |
| 核心知识 | 一句话，只写知识点本身，不带论证 |
| 简明解释 | 2~4 句，用自己的话讲清原文论述；原文的限定条件与不确定语气（"仅在实验条件下""可能"）原样保留 |
| 例子或自测 | 优先用原文自带的例子（标注「例子」）；原文没有时改为自测题（标注「自测」），附一行参考答案要点 |

**五条硬约束**：

| 约束 | 行为 |
|------|------|
| 提取真正重要的知识 | 概念、原理、可照做的方法、关键数据优先；排除过渡与客套 |
| 一卡一点 | 每张卡只回答一个问题；按子要点拆卡，不按段落机械切分 |
| 删除重复内容 | 同一观点出现多次只做一张卡，各处补充细节并入"简明解释" |
| 不编造 | 原文没有的数据、结论、人名、术语、例子一律不写；"简明解释"只重组原文已有信息 |
| 不强行凑数量 | 5~8 张是目标区间不是配额；候选点超过 8 个时只保留最重要的 8 个，并注明"另有 N 个次要知识点未展开" |

**输出行为**：卡片语言跟随原文语言；在回复中完整展示全部卡片；输入为本地文件时另存为 `<原文件名>-知识卡片.md`（与源文件同目录）；卡片不足 5 张时在开头说明原因。

## 安装

需要 ZCode（支持 `.agents/skills/` 技能发现）。把 `knowledge-cards/` 整个文件夹复制到技能目录之一：

| 范围 | 路径 |
|------|------|
| 所有项目可用 | `~/.agents/skills/knowledge-cards/` |
| 仅当前项目 | `<项目>/.agents/skills/knowledge-cards/` |

注意：文件夹名 `knowledge-cards` 与 SKILL.md 中的 `name` 字段必须一致，若要改名两处需同步。无需其他配置，ZCode 会自动发现并按需加载。

## 使用方法

安装后用自然语言即可触发，例如：

- 「把这篇文章做成知识卡片：〈粘贴全文〉」
- 「帮我把 `notes/认知偏差.txt` 整理成学习卡片」
- 「提炼一下这篇读书笔记的知识点：……」
- 「这篇文章给我做几张闪卡 / flashcards」

支持的输入：粘贴的文本、`.md` 文件、`.txt` 文件（多个文件逐个处理、分别输出）。其他格式（如 PDF、Word）会被告知暂不支持，不会强行解析。用户明确指定卡片数量时以用户为准，但"一卡一点"和"不编造"仍然生效。

## 输入输出示例

**输入**（[examples/费曼技巧.md](examples/费曼技巧.md) 节选）：

> 第二步，讲到卡壳的地方就停下来，回到原始材料。注意：只查你讲不出来那一小段，不要把整章重读一遍。卡壳的位置精确标记了你理解的缺口。

**输出**（对应的卡片之一，完整输出见 [examples/费曼技巧-知识卡片.md](examples/费曼技巧-知识卡片.md)）：

```markdown
## 卡片 2 · 卡壳的位置就是理解的缺口，回查只查那一小段

**核心知识**：讲不下去时停下，回到原始材料，只查卡壳的那一小段，不要重读整章。

**简明解释**：卡壳精确标记了理解的缺口，所以回查应该由卡壳点驱动，而不是从头再读一遍。

**自测**：为什么卡壳后只查那一小段、不重读整章？
> 参考要点：卡壳的位置已经精确定位了理解缺口，重读整章会稀释重点。
```

**更多完整示例**：

| 示例 | 输入 | 输出 |
|------|------|------|
| 短文（约 6 段） | [examples/费曼技巧.md](examples/费曼技巧.md) | 5 张卡片 · [examples/费曼技巧-知识卡片.md](examples/费曼技巧-知识卡片.md) |
| 50 个配方的菜谱书 | 《祖传50种小咸菜的制作方法》（用户粘贴） | 7 张通用知识卡片 · [cards/祖传50种小咸菜的制作方法-知识卡片.md](cards/祖传50种小咸菜的制作方法-知识卡片.md) |

第二个例子展示了 skill 对超长内容的取材策略：50 个配方不逐一做卡，而是提炼贯穿全书的 7 条通用做法（坛沿水密封、老盐水打底、先盐腌再酱制、卫生防坏等），每条注明原文出处。

## 工作流程

skill 内部按五步执行：**获取内容**（读取文件或使用粘贴文本）→ **通读并列出候选知识点** → **筛选合并**（一卡一点、去重、超量择优）→ **按四字段格式撰写并逐张自检** → **输出**（回复完整展示，文件输入另存）。
